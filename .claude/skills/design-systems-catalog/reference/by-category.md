## Decision Cheatsheet

| Need | First-line picks |
| --- | --- |
| React app, OSS, MIT-ish | Chakra UI, Mantine, Radix + shadcn/ui, MUI |
| Accessibility-first | USWDS, GOV.UK, IBM Carbon, Adobe Spectrum |
| Enterprise admin UI | Atlassian, Fluent UI, Carbon, Cloudscape, Polaris |
| E-commerce storefront | Polaris, Gestalt, Backpack |
| Government / public sector | USWDS, GOV.UK, DSFR, Italia, SGDS |
| Voice & tone microcopy | Mailchimp, Monzo, Polaris, Atlassian |
| Headless / unstyled primitives | Radix UI, Shoelace, Reshaped |
| Tailwind-friendly | shadcn/ui, Flowbite, Untitled UI |
| Web Components | Shoelace, KoliBri, Vanilla |
| Figma kit available | Polaris, Carbon, Fluent, Material, Spectrum, Gestalt, Atlassian, Untitled UI, Flowbite |
| Mobile-first | Material, Apple HIG, Skyscanner Backpack |
